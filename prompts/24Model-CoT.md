## Stage A Unsafe-action Identification and Classification

```text
你是一名安全科学领域事故调查专家。当前要执行的任务是不安全动作识别与分类

【事故报告】

{{ACCIDENT_TEXT}}

【Act定义和分类编码】

{{ACT_DICTIONARY}}

【分析问题】

Q1：事故文本中有哪些人员动作或物质状态与事故的发生或发展直接相关？
Q2：根据Act定义，逐一判断这些动作或状态是否涉及违规、是否导致或影响事故发生发展，或者是否属于风险评估所识别的不安全状态。
Q3：根据分类定义，为每个确认的不安全动作或不安全物态选择最适用的Act代码。

【分析要求】

1. 识别事故文本能够支持的所有不安全动作或不安全物态，不要遗漏不同实施者、对象或过程对应的独立动作。
2. 严格依据事故文本，不得补充文本中未出现的行为或状态。
3. 每个结果只选择一个最适用的Act代码；证据不足时使用None。
4. `evidence`填写支持判断的事故文本依据，`rationale`简要说明编码理由。

仅返回以下JSON结构，不要输出Markdown或其他文字：

{
  "文本编号": "{{TEXT_ID}}",
  "unsafe_actions": [
    {
      "action_id": "A1",
      "action_description": "",
      "Act_code": "",
      "evidence": "",
      "rationale": ""
    }
  ]
}

【输出要求】

- 必须返回合法JSON。
- 不允许使用Markdown代码块。
- 不允许输出JSON以外的解释文字。
- 所有键和值必须使用双引号。
- 所有数组和对象必须完整闭合。
- 没有充分文本证据支持的层级使用代码None。
```
